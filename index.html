Iniciación Práctica 1

Conexión sencilla de LEDs

Monta tu primer circuito: dos LEDs que se turnan para encenderse desde el código. Es la base de todo lo que viene después.

Pista: ver imágenes de conexiones y bloques

Qué vas a aprender

Cómo cerrar un circuito con la placa, qué hace una resistencia limitadora y cómo controlar dos pines digitales con digitalWrite() para que se turnen.

Material

  • 1 placa Arduino Uno (R3 o R4 WiFi)
  • 1 LED rojo y 1 LED verde
  • 2 resistencias de 220 Ω
  • Cables de conexión
  • 1 protoboard

Montaje

  1. Coloca los dos LEDs en la protoboard. Fíjate en la pata más larga (ánodo, +) y la más corta (cátodo, −) de cada uno.
  2. Conecta el pin digital 13 a una resistencia de 220 Ω, y esta al ánodo del LED rojo.
  3. Conecta el pin digital 12 a otra resistencia de 220 Ω, y esta al ánodo del LED verde.
  4. Conecta los cátodos de ambos LEDs a GND.

Código

const int ledRojo = 13;
const int ledVerde = 12;

void setup() {
  pinMode(ledRojo, OUTPUT);
  pinMode(ledVerde, OUTPUT);
}

void loop() {
  digitalWrite(ledRojo, HIGH);
  digitalWrite(ledVerde, LOW);
  delay(1000);
  digitalWrite(ledRojo, LOW);
  digitalWrite(ledVerde, HIGH);
  delay(1000);
}

Para comprobar que lo entiendes

Cambia los valores de delay() y observa qué ocurre. ¿Qué pasa si usas dos valores distintos para cada LED? ¿Sabrías hacer que los dos parpadeen muy deprisa?

Intermedio Práctica 2

LED controlado por un pulsador

Añade una entrada a tu circuito: un pulsador que decide, con una condición en el código, si el LED está encendido o apagado.

Pista: ver imágenes de conexiones y bloques

Qué vas a aprender

A leer una entrada digital con digitalRead() y a usar una estructura if / else para que el circuito reaccione a lo que ocurre fuera de la placa.

Material

  • 1 placa Arduino Uno
  • 1 LED
  • 1 resistencia de 220 Ω (para el LED)
  • 1 pulsador de 4 patas
  • 1 resistencia de 10 kΩ (para el pulsador)
  • Cables y protoboard

Montaje

  1. Conecta el pin digital 10 a una resistencia de 220 Ω, y esta al ánodo del LED. El cátodo va a GND.
  2. Coloca el pulsador a caballo del canal central de la protoboard.
  3. Conecta una pata del pulsador a 5V.
  4. Conecta la pata opuesta al pin digital 8, y añade desde ese mismo punto una resistencia de 10 kΩ hasta GND. Esta resistencia de "pull-down" asegura que el pin lea LOW cuando nadie pulsa el botón.

Código

const int botonPin = 8;
const int ledPin = 10;

void setup() {
  pinMode(botonPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  if (digitalRead(botonPin) == LOW) {
    digitalWrite(ledPin, LOW);   // no pulsado: LED apagado
  } else {
    digitalWrite(ledPin, HIGH);  // pulsado: LED encendido
  }
}

Es la misma lógica que en el bloque "si leer pin digital 8 = 0": mientras el botón no esté pulsado el pin lee 0 y el LED permanece apagado; en el momento en que lo pulsas, el pin pasa a leer 1 y el LED se enciende.

Antes del próximo reto: el LED tricolor (RGB)

Un LED tricolor no tiene 2 patas, sino 4: tres corresponden a los colores rojo, verde y azul, y la cuarta es una pata común. Según el modelo, esa pata común se conecta a GND (cátodo común, el más habitual en kits escolares) o a 5V (ánodo común) — comprueba el datasheet del tuyo antes de montarlo.

Cada uno de los tres colores necesita su propia resistencia de 220 Ω y su propio pin. Si usas digitalWrite() el color enciende a máxima intensidad; si usas analogWrite() en un pin PWM puedes regular la intensidad de cada color y mezclarlos.

Reto 2

Un pulsador, tres colores

Usa un único pulsador para ir cambiando el color de un LED tricolor: rojo, luego verde, luego azul, y vuelta a empezar cada vez que lo pulsas.

Material disponible

  • 1 placa Arduino Uno
  • 1 LED tricolor (cátodo común)
  • 3 resistencias de 220 Ω
  • 1 pulsador
  • 1 resistencia de 10 kΩ
  • Cables y protoboard

Cuidado: si en cada vuelta del loop() compruebas si el botón está pulsado y cambias de color cuando lo está, el color cambiará decenas de veces mientras lo mantengas apretado, porque el loop() se ejecuta miles de veces por segundo.

Pista, si te atascas

Lo que quieres detectar no es "el botón está pulsado", sino el instante en que pasa de no estarlo a estarlo (un "flanco de subida"). Guarda en una variable el estado del botón en la vuelta anterior del loop() y compáralo con el estado actual: solo cambia de color cuando antes era LOW y ahora es HIGH.

Avanzado Práctica 3

Sensor de luz (LDR) y un LED

Sustituye el pulsador por un sensor: una fotorresistencia (LDR) que decide, según la luz ambiente, si el LED debe encenderse.

Pista: ver imágenes de conexiones y bloques

Qué vas a aprender

A leer una entrada analógica con analogRead() (valores de 0 a 1023, no solo 0 o 1) y a comparar esa lectura con un umbral para tomar una decisión.

Material

  • 1 placa Arduino Uno
  • 1 LDR (fotorresistencia)
  • 1 resistencia de 10 kΩ (para el divisor de tensión del LDR)
  • 1 LED
  • 1 resistencia de 220 Ω (para el LED)
  • Cables y protoboard

Montaje

  1. Conecta una pata del LDR a 5V.
  2. Conecta la otra pata del LDR al pin analógico A0, y desde ese mismo punto añade una resistencia de 10 kΩ hasta GND. Esto forma un divisor de tensión: cuanta menos luz hay, mayor es la resistencia del LDR y más alto el valor que lee A0.
  3. Conecta el pin digital 13 a una resistencia de 220 Ω, y esta al ánodo del LED. El cátodo va a GND.

Código

const int ldrPin = A0;
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int valor = analogRead(ldrPin);

  if (valor < 300) {
    // Hay luz: apagamos el LED
    digitalWrite(ledPin, LOW);
  } else {
    // No hay luz: encendemos el LED
    digitalWrite(ledPin, HIGH);
  }
}

El valor 300 es un umbral orientativo: abre el monitor serie, imprime valor con Serial.println() y comprueba qué número da tu LDR con la luz de tu aula, para ajustarlo si hace falta.

Avanzado Práctica 4

Servomotor

Deja de encender luces y empieza a mover algo: controla el ángulo de un servomotor con la librería Servo.

Pista: ver imágenes de conexiones y bloques

Qué vas a aprender

A usar una librería (código que ya han escrito otros para resolver un problema común) y a mover un servomotor a un ángulo concreto con write().

Material

  • 1 placa Arduino Uno
  • 1 servomotor (tipo SG90 o similar)
  • Cables de conexión

Montaje

  1. El servo tiene 3 cables. El marrón o negro va a GND.
  2. El rojo va a 5V.
  3. El naranja o amarillo (señal) va al pin digital 8.

Con un solo servo pequeño, la placa Arduino puede alimentarlo directamente. Si en el futuro usas varios servos o uno de más fuerza, necesitarás una fuente de alimentación externa para ellos.

Código

#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(8);
}

void loop() {
  miServo.write(180);
  delay(2000);
  miServo.write(0);
  delay(2000);
}

La librería Servo viene instalada por defecto en el IDE de Arduino: solo hace falta el #include, no necesitas descargar nada.

Si simplemente sustituyes los digitalWrite() del Reto 3 por miServo.write() dentro del mismo if, el servo recibirá la misma orden decenas de veces por segundo y puede vibrar o hacer ruido. Avanzado Práctica 5

Sensor de temperatura y monitor serie

Lee un sensor de temperatura, conviértelo a grados y observa los datos en tiempo real desde el ordenador con el monitor serie.

Pista: ver imágenes de conexiones y bloques

Qué vas a aprender

A convertir una lectura analógica en una magnitud con sentido (grados centígrados) y a usar Serial.print() para ver esos datos en el ordenador mientras el programa se ejecuta.

Material

  • 1 placa Arduino Uno
  • 1 sensor de temperatura analógico (tipo TMP36)
  • 1 LED
  • 1 resistencia de 220 Ω
  • Cables y protoboard

Montaje

  1. Conecta la pata de alimentación del sensor a 5V y la de tierra a GND. Comprueba en el datasheet cuál es cuál: en un TMP36, mirando la cara plana, suelen ir en el orden Vcc – señal – GND.
  2. Conecta la pata de señal del sensor al pin analógico A0.
  3. Conecta el pin digital 7 a una resistencia de 220 Ω, y esta al ánodo del LED. El cátodo va a GND.

Código

const int tempPin = A0;
const int ledPin = 7;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(tempPin);
  float voltaje = lectura * (5.0 / 1024.0);
  float temperatura = (voltaje - 0.5) * 100.0;

  Serial.print("Temperatura = ");
  Serial.print(temperatura);
  Serial.println(" C");

  if (temperatura > 50) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }

  delay(500);
}

Abre el monitor serie (icono de la lupa arriba a la derecha del IDE, o Herramientas → Monitor Serie) y comprueba que la velocidad indicada coincide con el 9600 de Serial.begin(). Calienta el sensor con los dedos para ver cómo cambia la lectura.

Avanzado Práctica 6

Sensor de ultrasonidos y dos LEDs

Mide una distancia con un sensor de ultrasonidos de un solo pin de señal (tipo PING))) y enciende un LED distinto según si algo está cerca o lejos.

Pista: ver imágenes de conexiones y bloques

Qué vas a aprender

Cómo funciona un sensor de ultrasonidos por debajo: envía un pulso, cronometra cuánto tarda en volver el eco con pulseIn() y, a partir de ese tiempo, calcula una distancia.

Material

  • 1 placa Arduino Uno
  • 1 sensor de ultrasonidos de un solo pin de señal (tipo PING)))
  • 1 LED rojo y 1 LED verde
  • 2 resistencias de 220 Ω
  • Cables y protoboard

Montaje

  1. Conecta el pin V (5V) del sensor a 5V y el pin GND a GND.
  2. Conecta el pin SIG del sensor al pin digital 10.
  3. Conecta el pin digital 7 a una resistencia de 220 Ω, y esta al ánodo del LED rojo. Cátodo a GND.
  4. Conecta el pin digital 2 a una resistencia de 220 Ω, y esta al ánodo del LED verde. Cátodo a GND.

Código

const int pingPin = 10;
const int ledRojo = 7;
const int ledVerde = 2;

void setup() {
  pinMode(ledRojo, OUTPUT);
  pinMode(ledVerde, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Enviamos el pulso de disparo
  pinMode(pingPin, OUTPUT);
  digitalWrite(pingPin, LOW);
  delayMicroseconds(2);
  digitalWrite(pingPin, HIGH);
  delayMicroseconds(5);
  digitalWrite(pingPin, LOW);

  // Escuchamos cuánto tarda en volver el eco
  pinMode(pingPin, INPUT);
  long duracion = pulseIn(pingPin, HIGH);
  long distancia = duracion / 29 / 2;  // en centímetros

  Serial.print(distancia);
  Serial.println(" cm");

  if (distancia <= 100) {
    digitalWrite(ledVerde, LOW);
    digitalWrite(ledRojo, HIGH);
  } else {
    digitalWrite(ledVerde, HIGH);
    digitalWrite(ledRojo, LOW);
  }

  delay(200);
}

El mismo pin hace de "altavoz" (envía el pulso, en modo OUTPUT) y de "oído" (escucha el eco, en modo INPUT) en momentos distintos: por eso cambiamos su pinMode() dos veces dentro del mismo loop().

La última pieza del taller

Reto final: diseña tu propia simulación

Aquí no hay montaje ni código de partida. Te toca a ti decidir qué construir, combinando lo que ya sabes de todas las prácticas anteriores.

Qué tiene que incluir tu proyecto

  • La placa Arduino (R3 o R4 WiFi).
  • Al menos tres de estos elementos, combinados con un propósito claro: uno o varios LEDs, el sensor de ultrasonidos, el LDR, un pulsador.
  • Una idea o problema real detrás: no vale conectar elementos sin más, tiene que "servir para algo" — una alarma, un sistema de aviso, un juego, una ayuda para alguien...

Cómo trabajar el reto

  1. Diseña primero, monta después. Antes de tocar un solo cable, dibuja o describe qué hace tu proyecto y qué sensor o entrada activa cada salida.
  2. Simúlalo. Monta el circuito y prueba el código en un simulador antes de montarlo físicamente, igual que hemos visto en las prácticas anteriores.
  3. Documenta tus decisiones. Por qué elegiste esos elementos, qué problema resuelven juntos y qué parte te costó más resolver.
  4. Móntalo en el aula. Cuando el código funcione en la simulación, reproduce el circuito con el material real.

Qué vas a entregar

  • El enlace a tu simulación.
  • El código, comentado en las partes clave.
  • Una explicación breve (unas líneas bastan) de qué hace tu proyecto y por qué elegiste esos elementos.

No hay pistas para este reto. Si te atascas, vuelve a una práctica anterior parecida a lo que quieres construir y adapta lo que ya funcionó allí.
